# Conservative Churning Policy (V1)

## Scope
Single-user local tracker for predictable sign-up bonus value and disciplined execution.

## Non-negotiable defaults
- Pay in full every month.
- No manufactured spending.
- No buying groups.
- No 0% APR float strategy.
- No business cards in V1.
- Cash-equivalent valuations only.

## Approval pacing
- Max one new personal card application every 90 days unless a manual override is documented.
- If at 4/24, mark Chase as warning.
- If at 5/24+, mark Chase as blocked.

## Credit-score guardrails
- Keep statement utilization low and stable.
- No applications if a payment was missed in prior 12 months.
- Confirm autopay + manual pay-in-full check monthly.

## Annual-fee review
- Trigger review task 30 days before fee anniversary.
- Default decision order: retain if net expected value remains positive; else downgrade/product change; else close.

## Weekly ritual (pilot)
- Update spend entries.
- Confirm pay-in-full status.
- Review dashboard alerts and due dates.
- Review opportunities with rule snapshot dates before applying.
