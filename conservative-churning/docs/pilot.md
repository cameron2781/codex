# 30-Day Pilot Workflow

1. Seeded card catalog + backfilled history loaded from migrations.
2. Every week:
   - Open `/dashboard`.
   - Resolve overdue and due-soon alerts.
   - Confirm monthly pay-in-full checks.
   - Review `/opportunities` and `/rules` snapshot dates.
3. Capture friction points in notes, then adjust schema only after repeated pain appears.
4. At day 30, evaluate:
   - Net reward value trend.
   - Missed deadlines count.
   - Whether lifecycle states covered real events (candidate → closed).
